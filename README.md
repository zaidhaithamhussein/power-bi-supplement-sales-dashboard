# Supplement Sales Analytics Dashboard | Power BI

A university Business Intelligence project built in **Microsoft Power BI Desktop** to explore sales and pricing patterns for sports nutrition products, including **creatine, pre-workout, and protein supplements**.

## Report pages

| Page | What it explores |
| --- | --- |
| **Creatine Dashboard** | Revenue trends, units sold, average price, sales rank, and date filters |
| **Pre-Workout Dashboard** | Revenue trends, units sold, pricing, sales rank, and date filters |
| **Protein Dashboard** | Revenue trends, units sold, pricing, sales rank, and date filters |
| **Combined Data Dashboard** | Product-level comparisons of sales, discounts, prices, units sold, and sales performance index (SPI) |
| **Forecasting** | Revenue forecasts for creatine, pre-workout, and protein (using Power BI forecasting features) |

## Features

- Interactive Power BI visuals: line charts, bar/column charts, scatter plots, pie chart, gauges, and KPI cards
- Product and date slicers
- Separate category dashboards and a combined comparison view
- Configured revenue forecasts with confidence intervals
- Embedded Power BI data model

## Project file

- [`FinalBI.pbix`](FinalBI.pbix) — original, unmodified Power BI report

## How to open

1. Install **Microsoft Power BI Desktop**.
2. Download `FinalBI.pbix` from this repository.
3. Open the file in Power BI Desktop and explore the five report pages.
4. If Power BI requests a data-source refresh, check the query/data source settings; the original source paths may not be available on another computer. The report includes an embedded data model.
